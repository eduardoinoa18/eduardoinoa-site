# eduardoinoa.com

Static website for **Eduardo Inoa, REALTOR®** — The Fermin Group at Century 21 North East. Bilingual (EN/ES), Merrimack Valley (MA) and Southern NH. Hosted on **Vercel** (framework preset "Other", no build command, output = repo root). Leads go to the Marketora inbox → Follow Up Boss / RealScout.

## Layout

```
index.html                 home (hand-edited; section ids are a contract — Marketora decks deep-link to them)
buyers/ sellers/           Buyer & Investor / Seller presentations (self-contained "Path B" decks; also uploaded to Marketora)
posts/<slug>.html          journal articles (hand-edited)
landing.css / landing.js   shared design system + lead forms for every generated page
market.js / market.css     Market Pulse block (home, town pages, home value, Marketora embed); reads market.json
market.json                weekly snapshot (GitHub Action, Mondays 7 AM ET)
img/                       logos, portraits, favicons; img/photos/ = licensed photography + manifest.json + CREDITS.md
cash-offer/ home-value/    landing pages        ┐
towns/ es/ journal/        town pages, Spanish  │ GENERATED by tools/ — edit the source in tools/pages + tools/data,
listings/ credits/         pages, indexes       ┘ then regenerate. Don't hand-edit these outputs.
sitemap.xml robots.txt     generated
vercel.json                clean URLs, redirects (www, vanity domains, /es aliases), headers
tools/                     local generator + QA (not deployed; see .vercelignore)
scripts/update_market.py   the weekly market refresh (run by .github/workflows/market.yml)
```

## Everyday tasks

```bash
cd tools
npm install          # once
npm run gen          # regenerate generated pages + sitemap + analytics/verification tags
npm run qa           # pre-deploy static checks (must pass)
```

Then commit and push; Vercel deploys `main` automatically. The "Update market data" workflow also commits to `main` every Monday, so `git pull --rebase` before you push.

- **After a market update** (or any change to `market.js` / `market.css`) — `node sync-decks.mjs` copies the Market Pulse code and snapshot into the decks (they are self-contained for Marketora), then `npm run gen`.
- **Share images** — every generated page and post gets a branded 1200×630 card in `img/og/` (its own photo + headline), made by `npm run gen`.
- **Leads relay** — `api/lead.js` (Vercel function) forwards form posts to the Marketora inbox and returns the real result; forms fall back to the direct send and then email if it fails. Test safely with an invalid email + short phone (the inbox answers 422 and stores nothing).
- **One-off deck helpers** — `node perf-assets.mjs` (favicon.ico, small nav logo, non-blocking deck fonts) and `node a11y-decks.mjs` (tablist roles, reviews link); both are idempotent.
- **Deck links** — `/buyers?town=lowell` (or `?town=salem-nh`) opens the presentation on that town's market; a Marketora `?c=` config with a property address wins. Toolkit deep links: `/buyers#toolkit/afford|payment|cash|offer|rentbuy|rental|valuation|strategy|flip|wholesale|reports`, `/sellers#tool-equity`.

- **Change a stat, phone, address or link** — `tools/site.config.json`, then `npm run gen`. The home page, decks and posts are hand-edited: search them for the same text. The `$20M+` figure is pending MLS confirmation; if it's under $20M, change every occurrence to "nearly $20M".
- **GA4 / Search Console / Bing** — put the IDs in `tools/site.config.json` (`ga4Id`, `googleSiteVerification`, `bingSiteVerification`) and run `npm run gen`. GA4 sends `generate_lead` with `lead_source` on every successful form.
- **Add a town page** — content lives in `tools/data/towns.json`; pages come from `tools/pages/towns.mjs`.
- **Add a journal post** — copy an existing `posts/<slug>.html`, edit, add it to the journal index data in `tools/pages/journal.mjs`, run `npm run gen`.
- **Photos** — `img/photos/manifest.json` lists every photo with alt text (EN/ES), license and credit. Only add photos you have the right to use; the credit prints in the footer and on `/credits`.
- **Run locally** — `npx serve .` from the repo root (clean URLs work the same as on Vercel).
